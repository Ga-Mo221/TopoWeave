Retopology add-on for Blender

Sketch the strokes.
Weave the mesh.

TopoWeave turns a few strokes on a 3D surface into an editable network and a connected quad mesh.

StrokesSurfaceQuads

The idea

Less vertex wrestling.
More thinking about form.

  1. 1

    Sketch the flow

    A few deliberate strokes on the surface describe the structure you want.

  2. 2

    Stay in control

    Strokes become a network of nodes and arcs. Edit it any time and the mesh follows.

  3. 3

    Weave the mesh

    Each closed region becomes a patch, and subdivisions match so the whole mesh stays connected.

Inside the tool

Everything a full model needs.

Mesh patterns

O-grid, transition, fillet and patterns you save yourself. Pick the flow that fits each region.

Cylinder & Bridge

Stroke across an arm or leg to ring it, then bridge two rings.

Mesh tweak

Grab, Smooth and Relax right on the generated mesh.

Auto Retopo

Builds a starting network from QuadriFlow, so you only fix what is wrong by hand.

Issue review

Highlights missing faces, skewed quads and bad poles, one by one.

UV-aware

Turn UV seams into strokes, preview UVs, copy them on Generate.

Tablet-friendly

A virtual wheel replaces every scroll action when you use a pen.

Auto backup

Your network is also kept outside the .blend file and can be restored.
